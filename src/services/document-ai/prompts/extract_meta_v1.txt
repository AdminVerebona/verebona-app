## Raisonnement préalable obligatoire

Avant de remplir les champs, demande-toi : **Quel est l'objet principal de ce document ? Quelle est sa finalité ?**

- Un acte notarié (servitude, titre de propriété, hypothèque) → document juridique sur des droits réels. Il peut mentionner des équipements ou des pièces dans ses clauses, mais son objet n'est pas cet équipement.
- Une facture → document commercial pour une prestation ou un achat précis. Peut concerner un équipement si la prestation porte directement sur lui.
- Un diagnostic (DPE, amiante…) → certificat technique du bien. Concerne le bien immobilier dans son ensemble, pas un équipement spécifique.
- Un contrat d'entretien → peut concerner un équipement si le contrat porte explicitement sur lui (ex : contrat de maintenance chaudière).
- Une notice / manuel → concerne l'équipement décrit dans le manuel.

**Règle fondamentale** : les associations (bien, pièce, équipement) se déduisent de la **finalité** du document, pas de la présence de mots-clés dans son texte. Un équipement cité en exemple, dans une clause, dans une description de contexte ou dans un attendu juridique n'est PAS l'objet du document.

## Champs extraction

- proposedTitle : titre synthétique du document (ex : "Facture EDF – Électricité T4 2024", "Devis chaudière Viessmann"), max 80 caractères
- proposedDescription : description courte et lisible, visible par l'utilisateur final. **Maximum 200 caractères, 1 à 2 phrases.** Ton sobre, factuel. Commence directement par le contenu, sans aucun préfixe "Description :", "Photo de", "Image de", "Document de". Ex : "Facture EDF de 87,50 € pour l'électricité du T4 2024." / "Chaudière à condensation Viessmann Vitodens 200 installée dans la cuisine."
- proposedFunctionCode : un des codes de la taxonomie ci-dessus (en MAJUSCULES), ou null
- proposedFunctionLabel : libellé humain correspondant au code, ou null
- proposedCilRubricCodes : tableau des codes CIL présents dans ce document (peut être vide [])
- proposedDate : date du document au format ISO 8601 (YYYY-MM-DD), ou null
- proposedDateType : "explicit" si la date est clairement indiquée, "derived" si déduite du contexte, null si absente
- proposedSupplier : nom commercial ou raison sociale de l'entreprise qui émet le document. Ne jamais mettre une adresse ou un nom de client.
- proposedSupplierCoordinates : coordonnées du fournisseur émetteur si présentes dans le document (email, phone, website, adresse postale, siren, siret, vatNumber, iban, ibanHolderName). Règle SIREN/SIRET : si l'identifiant est à 9 chiffres → mettre dans "siren" (siret=null) ; si 14 chiffres → mettre dans "siret" (siren=les 9 premiers chiffres). Ne jamais prendre les coordonnées du client. null si aucune coordonnée présente, null pour chaque champ absent.
- proposedAmountCents : montant total TTC en centimes (entier, ex: 4990 pour 49,90 €), ou null
- proposedLinks.assetReference : référence textuelle au bien principal du document, ou null
- proposedLinks.matchedAssetId : id du bien correspondant dans la liste ci-dessus, ou null. Se déduit de la finalité du document : une facture de travaux sur un logement → ce logement ; un contrat de maintenance d'un véhicule → ce véhicule. Ne jamais associer un document administratif générique (mandat SEPA, RIB, assurance multi-bien, courrier général) à un bien. En cas de doute, retourner null.
- proposedLinks.roomReference : nom d'une pièce du bien UNIQUEMENT si le document traite directement de cette pièce (travaux dans cette pièce, photo de cette pièce). UNIQUEMENT pour IMMOBILIER. Toujours null pour VEHICULE, OBJECT. Null si le document est d'ordre juridique, administratif ou financier général.
- proposedLinks.equipmentReference : nom d'un équipement fixe du logement UNIQUEMENT si le document a pour objet principal cet équipement : facture d'achat de cet équipement, garantie fabricant de cet équipement, notice/manuel de cet équipement, contrat d'entretien portant explicitement sur cet équipement, rapport de maintenance/diagnostic de cet équipement. UNIQUEMENT pour IMMOBILIER. Toujours null pour VEHICULE et OBJECT. Toujours null si le document est un acte notarié, une servitude, un titre de propriété, un diagnostic global du bien, un courrier, une facture non relative à cet équipement — même si l'équipement y est mentionné.
- extractionConfidence : entre 0.0 et 1.0
- extractionNotes : observations utiles (langue, ambiguïtés, champs douteux)
